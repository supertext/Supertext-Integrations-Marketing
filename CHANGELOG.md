Pages of systems without a plugin no longer ask *How can I translate … today?* when they have a *How to translate … today* section. Microsoft 365's *Is it free?* answer now explains that the add-ins are included in the Advanced and Enterprise subscriptions.
- Microsoft 365 no longer says an API key is needed: the add-ins only need a Supertext login (*Getting started* and the questions, all four languages).

The announcement bar is light mint so it stands out from the page.
- New Supertext look, as on the neo site: ABC Ginto Nord headings, the Supertext wordmark in a dark green header bar, warm off-white cards without borders and 10 px corners, a light announcement bar, the *Most popular* plan with its blue-green label, highlighted words in the dark call-to-action, and a muted green footer card.

- Microsoft 365: the add-ins come with the Supertext Advanced and Enterprise subscriptions, so its page links to supertext.com's subscriptions (*Included in Supertext Advanced*) instead of this site's plans, and the plans no longer offer it as a platform (`web/src/lib/inSubscription.js`).

The roadmap article no longer lists it among the open requests.
- New plugin releases show on the site within the hour: the GitHub release sync runs every hour (at :17) when `GITHUB_TOKEN` is set, nightly without it, and on every start of the CMS when the last sync is more than an hour old (before: nightly only, so a release could take a day to appear).

- Search on the integration grid (start page and `/integrations`): finds integrations as you type by name, summary, type of integration, technology, category and hidden search words (new field *searchTerms*, filled for every integration, e.g. WooCommerce, Onlineshop, MCP), planned and requested systems included. The category counts follow the search, `?q=` makes a search linkable, and no result offers *Request it* with the system already filled in on the support form. Can be switched off per block (*showSearch*). All four languages.
- WordPress (WPML) added as its own integration (*In development*, right after WordPress (Polylang)): details, translation files, comparison with WPML's own AI translation, questions, the plugin's screenshot and its Plugin Health statistics (`supertext-wordpress-wpml`); created on the live site by a one-time content update and translated into German, French and Italian. Seed entries can now set their own slug (both WordPress plugins would otherwise be `wordpress`).
